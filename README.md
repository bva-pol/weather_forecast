# 🌤️ Метеостанция - Десктопное приложение погоды

Десктопное приложение для отображения текущей погоды и почасового прогноза температуры с использованием бесплатного API Open-Meteo. Поддерживает пользовательский список городов с сохранением конфигурации.

## ✨ Особенности

### 📊 Отображение погоды
- **Текущая погода**: температура, влажность, давление, скорость и направление ветра
- **Почасовой прогноз** на 4 дня (96 часов) с интерактивным графиком
- **Двойная ось X**: верхняя для дат, нижняя для времени
- **Адаптивный интерфейс**: формат отображения времени автоматически меняется в зависимости от размера окна
- **Интерактивные подсказки**: при наведении на точки графика показывается детальная информация

### 🏙️ Управление городами
- Встроенный редактор городов с удобным интерфейсом
- Добавление, редактирование и удаление городов
- Сохранение списка городов в конфигурационный файл `cities.conf`
- Восстановление стандартного списка городов
- Валидация координат при добавлении

### 🎨 Интерфейс
- Современный дизайн в стиле Material Design
- Адаптивная верстка, корректно работает при изменении размеров окна
- Поддержка системных тем Ubuntu (Fusion стиль)
- Читаемые шрифты и контрастные цвета
- Анимированные переходы при обновлении данных

## 🚀 Установка

### Системные требования
- **Ubuntu** 20.04, 22.04 или 24.04 (64-bit)
- **Qt** 5.12 или выше
- **Компилятор** с поддержкой C++11
- **Интернет-соединение** для получения данных о погоде

### Установка зависимостей

```bash
# Обновление пакетов
sudo apt update

# Установка Qt5 и необходимых модулей
sudo apt install -y \
    qt5-default \
    qtbase5-dev \
    qtcharts5-dev \
    libqt5charts5-dev \
    build-essential \
    cmake \
    git

# Для Ubuntu 22.04+ может потребоваться
sudo apt install -y qtbase5-dev qt5-qmake
```
### Сборка из исходников
``` bash
# Клонирование репозитория
git clone https://github.com/bva-pol/weather_forecast.git
cd weather_forecast

# Конфигурация и сборка
qmake ./weather_forecast.pro
make -j$(nproc)

# Запуск
./build/weather_forecast
```
